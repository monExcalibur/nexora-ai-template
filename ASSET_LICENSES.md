# Assets and third-party notices

Nexora AI uses local React/CSS/SVG product illustrations and a system font stack. No stock photography, remote font download, image service or live AI SDK is included. The Nexora favicon and optional FlowPilot logo are supplied concept assets; both brands are fictional.

Complete unmodified runtime package notices are retained in the static build:

- [React MIT notice](public/licenses/react-MIT.txt): React, React DOM and Scheduler have matching MIT license text.
- [Lucide notice](public/licenses/lucide-LICENSE.txt): ISC plus the full Feather-derived MIT notice and copyright attribution.

The source packages retain their own notices during dependency installation. When upgrading runtime libraries, compare and refresh these public notice copies rather than removing attribution. Development tools are identified by package.json/package-lock.json and are not shipped as application runtime assets.

No social preview image is bundled. Supply an appropriately licensed, optimized image before configuring `seo.socialImage`; no missing file should be advertised. New photos, logos and fonts require their own usage rights/notices.

Third-party licenses do not specify a license for the application source. Select a source-code redistribution license separately before offering template reuse. No claim about development tools or real client commissions is made by these asset descriptions.
